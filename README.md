## ✨ Key Features

1. **Responsive Dark Cinematic Design**
   - Deep navy (`#070B14`) and charcoal aesthetic with electric blue and cyan accents.
   - Fully responsive layouts tailored for mobile phones, tablets, laptops, and ultra-wide displays.
   - Built to Apple Human Interface Guidelines standards with accessible contrast and touch-friendly controls.

2. **Balanced "Magical & Professional" Motion System**
   - **Aurora Gradients**: Continuous, subtle shifting aurora background.
   - **Ambient Particle Canvas**: Lightweight, battery-aware HTML5 canvas particle system that automatically pauses on background tabs (`document.hidden`).
   - **Desktop Cursor Spotlight**: Restrained radial spotlight following desktop mouse movement (disabled on touch devices).
   - **Portrait Halo & Light Sweep**: Ambient glow and subtle sheen on the authentic professional photograph.
   - **Accessibility**: Full `@media (prefers-reduced-motion: reduce)` compliance to disable non-essential motion.

3. **Interactive Project Showcase (`TiltCard`)**
   - Gentle 3D perspective tilt (max 4.5°) responding to cursor position.
   - Dynamic glare reflection and animated gradient border hover effects.
   - Fallbacks with touch-detection to prevent jitter on mobile devices.

4. **Career Experience Timeline**
   - Illuminated vertical spine tracing verified engineering milestones.
   - Pulsing beacon node for current role at Accenture and foundational node for TCS.
   - Documented metrics: 1,000+ operational users, ~15% network efficiency improvement, offline-first Core Data architectures, and Agile release ownership.

5. **AI / Machine Learning Engineering Showcase**
   - **PoleInspection Interactive HUD**: A demonstration simulator showing an image classification pipeline with live laser scanning, 4 interactive defect reticles (*Normal Pole*, *Broken Pole*, *Leaning Pole*, *Tree Interruption*), a 4-stage pipeline stepper (*Image Capture → AI Analysis → Defect Classification → Result*), and a Pause/Resume toggle.
   - **Social Media Sentiment Intelligence**: A concept explorer demonstrating multi-class sentiment categorization and conceptual RAG workflows for airline customer feedback.
   - **Ethical AI Disclosures**: Prominent demonstration badges indicating research/simulation data without overstating production status.

6. **Interactive Skills Matrix**
   - Organized into 5 distinct categories: *Core iOS Development*, *Architecture & Design Patterns*, *Networking & Persistence*, *Testing & CI/CD*, and *AI/ML Learning*.
   - Instant live search and category filter pills with keyboard accessibility.

7. **Direct Communication & Resume Viewer**
   - Integrated email composer prefilling inquiries into default mail clients.
   - In-app modal viewer for the official resume PDF with direct download support.

## 💻 Local Development

### Prerequisites
- **Node.js**: v20 or higher recommended (verified with Node.js 22)
- **npm**: v9 or higher

### 1. Clone the repository
```bash
git clone https://github.com/MunshiSarifulIslam/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
The application will start on `http://localhost:3000` with host listening on all network interfaces (`0.0.0.0`).

### 4. Type checking & Linting
```bash
npm run lint
```
Executes `tsc --noEmit` to validate TypeScript types across the entire project.

---

## 📦 Production Build

To compile a production-ready bundle:

```bash
npm run build
```

This generates an optimized, minified bundle in the `dist/` directory.

### Preview the production build
```bash
npm run preview
```

### Clean build artifacts
```bash
npm run clean
```
